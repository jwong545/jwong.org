overview

I rebuilt my homelab on open-source infrastructure so I can self-host production-style services. It currently runs my personal portfolio site (jwong.org) and an intranet with a dashboard.

goals

  • Keep critical services up when a single node fails.
  • Make every deployment repeatable instead of hand-configured.
  • Protect data against hardware failure with offsite backups.
  • Serve everything over HTTPS with sensible access rules.

what i built

  • Redundant critical services on [Proxmox VE / KVM / containers], so a single node failure does not take them down.
  • Automated [deployments / configuration] with [Ansible / GitHub Actions] to keep builds repeatable.
  • Weekly backups to an offsite location to protect against hardware failure and data loss.
  • Sites served over HTTPS behind [Nginx / Cloudflare] with [firewall / access rules].
